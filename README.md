# IRON LOG

Dark gym tracker for dumbbells and weight machines.

Open the site, pick gear, log sets, save templates, and track PRs. Data stays in your browser (`localStorage`).

## Use
- **Gear** — filter by dumbbell / machine / muscle, add custom moves
- **Train** — log weight × reps, rest timer after a completed set
- **Log** — session history
- **PRs** — best logged loads
- Home templates load a saved routine
